# 스피드 게임

눈 깜짝할 사이에 지나가는 사진을 보고 무엇인지 맞히는 게임 슬라이드입니다.

**바로 열기:** https://rmjunho.github.io/speed-game/

## 조작법
- 다음: → 키 · 스페이스 · 화면 클릭 · ▶ 버튼
- 이전: ← 키 · ◀ 버튼
- 다시 보기: R 키 · ⟳ 버튼
- 전체화면: F 키
- 왼쪽 아래 `제목 · 설명 · 1 · 2 · 3 · 4`로 각 문제 표지(문제 N)로 바로 이동
- 사진이 지나간 뒤 오른쪽 아래 `정답` 버튼으로 정답 페이지로 바로 이동

단계별 통과 시간: 1단계 0.25초 · 2단계 0.5초 · 3단계 1초
